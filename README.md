A GitHub-compatible git forge in one standalone Node process — git smart HTTP (upload-pack v2, receive-pack v0), the REST v3 API, GraphQL v4 and an MCP endpoint, all over a single in-memory store.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 MAKEFUN_SHOP_TOKEN=your-token node main.ts
```
